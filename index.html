Privacy Notice & Consent Declaration
TCS Korea Workplace · Continental Korea (CTK TCS Team)
This tool processes personal information in accordance with the Korea Personal Information Protection Act (PIPA). Please read the notice below and consent before proceeding.
Logged in as:
📋 1. Personal Information Collected
  • Work email address — identity verification via OTP authentication and access control
  • Session data — login time, session duration, and in-tool activity
  • Access & action logs — pages visited and actions performed within the tool
  • Approximate location data — city/region and country, derived from IP address at login (ipapi.co)
🎯 2. Purpose of Processing
  • Authentication & access control — to verify that only authorised Continental employees can access the tool
  • Security monitoring & anomaly detection — location data is used to detect abnormal access patterns (e.g. a Seoul-based account logging in from overseas will be flagged for review)
  • Usage analytics & abuse prevention — session and access logs used to monitor for misuse and track performance metrics
  • Admin oversight — authorised administrators can review session and access logs via the admin portal
🗓️ 3. Data Retention Period
Work email Session logs Access logs Location data

Maximum retention period: 6 months from the date of collection, after which data is automatically and permanently deleted. Aggregate, non-identifiable usage statistics may be retained beyond this period for KPI tracking purposes.
👁️ 4. Admin Portal & Employee Monitoring
Your tool usage is monitored and logged. In the event of a suspected policy violation or security incident, access may be suspended. Any such decision requires prior review and written approval from the following designated persons:
  • JinSeong Kim – Marketing Manager
  • Nikolaos Kyriazopoulos – Market Manager
🌐 5. Cross-Border Data Transfer
This tool operates using Supabase (cloud database) and ipapi.co (location data API). Personal information is processed through these services solely for the purposes stated above. Infrastructure may be located outside the Republic of Korea, which constitutes a cross-border transfer under PIPA.

Transfer destination Supabase · ipapi.co (global infrastructure)
Safeguards AES-256 encryption · RLS · Employee consent obtained via this declaration
